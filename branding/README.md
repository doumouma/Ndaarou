# Identité visuelle Ndaarou

Ressources vectorielles officielles du client Android TV `com.ndaarou.tv`.

- **Symbole** : lettre N intégrée à un bouton de lecture, en deux aplats sans relief, sans ombre, sans trait supplémentaire.
- **Logo vertical** : mot « Ndaarou » toujours centré **sous** le symbole, jamais à côté.
- **Couleurs** : graphite `#10191D`, menthe `#92D5C4`, blanc `#F7FAF9`.
- **Typographie** : tracés vectoriels issus d'Inter Display Bold ; aucun fichier de police requis à l'exécution.
- **Sources SVG** : `ndaarou-icon.svg`, `ndaarou-logo-vertical.svg`, `ndaarou-logo-inverse.svg` et `ndaarou-tv-banner.svg`.
- **Android** : ressources `smarttubetv/src/stfdroid/res/mipmap-nodpi/app_*.xml` natives au flavor `stfdroid` : icônes 192×192, logo compact 96×96, bannière 320×180 (16:9).

Les petits logos internes restent sans texte pour conserver leur lisibilité ; le nom apparaît sous le pictogramme dans le logo principal, la bannière et l'icône d'application.
